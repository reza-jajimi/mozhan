# Mozhan | Hair Keratin Studio

A luxury and minimalist website designed for a professional hair keratin and hair care studio.

## Project Status

This project was originally developed for a real business in the professional hair keratin industry.

The commercial project was discontinued before its final release. The source code was kept in the development environment and later published on GitHub as a portfolio and archived project.

## Technologies

- React 18
- TypeScript
- Vite 5
- React Router
- Framer Motion
- React Toastify
- Custom Responsive CSS

## Pages

- Home
- About
- Services
- Portfolio
- Packages
- FAQ
- Contact

## Features

- Luxury and minimalist UI
- Fully responsive navigation
- Mobile menu
- Page and section entrance animations
- Portfolio gallery with category filtering
- Package presentation with 2024 reference pricing
- Keyboard-accessible interactive controls
- Contact form success notification
- Clean component and data separation
- Persian RTL interface
- Custom responsive CSS architecture
- Reusable UI components

## Design

The project uses a custom CSS architecture instead of a utility-first CSS framework.

The interface was designed with a focus on:

- Minimalism
- Visual hierarchy
- Responsive layouts
- Consistent spacing and typography
- Smooth animations
- Persian RTL user experience

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production Build

Create an optimized production build:

```bash
npm run build
```

## Code Quality

Run ESLint to check the codebase:

```bash
npm run lint
```

## Project Structure

The project follows a component-based architecture with a clear separation between:

- Pages
- Reusable components
- Data
- Styles
- Assets

This structure makes the codebase easier to maintain and extend.

## Notes

This repository is maintained as a portfolio and archived project. The business information, package prices, and content reflect the original project context and may not represent a currently operating business.
